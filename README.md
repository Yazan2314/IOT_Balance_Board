## Details about the project:
An interactive, IoT-based balance board designed for physical therapy and rehabilitation. The system uses load cells to calculate the user's Center of Pressure (CoP). The data is processed locally by an ESP32 microcontroller and used to control a gamified application in real-time, allowing patients to perform rehabilitation exercises safely and interactively. 
Key features include real-time CoP tracking, offline data logging with automatic cloud synchronization, and a multi-user admin dashboard.

- Parameters: contains description of parameters and settings that can be modified IN YOUR CODE
